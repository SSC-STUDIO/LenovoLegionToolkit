## 首条评论

Maintainer here — UDT is the community continuation of Lenovo Legion Toolkit. Lightweight Windows utility for Legion/LOQ: power modes, RGB, battery, plugins. No telemetry, GPL-3.0.

We kept the old winget ID (LenovoLegionToolkit) so upgrades don't break. v4.2.1 just shipped with 2343/2343 tests passing and multi-language fixes.

Honest limit: full hardware control is for supported Lenovo gaming laptops; other PCs get basic mode + plugins. It also doesn't run a background service by design — tray-only, so some features need the app running.

Would love feedback from anyone who tries the basic mode on non-Lenovo hardware.
