Key features at a glance

Built around plugin extensions so device-specific tools grow without weighing down the base app. No background service, under 30 MB RAM.

Power & Performance

Fn+Q power modes, Custom Mode with fan curves, CPU/GPU power limits.

RGB & Lighting

Spectrum per-key RGB, 4-zone RGB, white backlight, and boot logo.

GPU Control

dGPU toggle, MUX switch, overclock, and deactivate dGPU cleanly.

Battery Care

Conservation mode, thresholds, and charge stop at 60% / 80%.

Actions & Macros

Automate tasks on AC connect, app launch, lid close, or a time schedule.

Sensors

Real-time CPU/GPU temperature, fan speed, and clock monitoring.

Plugin Extensions

CPU tools, GPU tools, network acceleration, shell, and mouse add-ons.

78+ Languages

Full localization with community translations on Crowdin.

No Bloat

Install in one line

Three ways to get UDT

Some package identifiers keep the legacy LenovoLegionToolkit name so old installs upgrade in place.

winget

Windows Package Manager

winget install SSC-STUDIO.LenovoLegionToolkit

Easiest. Use winget upgrade to stay current.

Scoop

Scoop manifest

scoop bucket add ssc-studio https://github.com/SSC-STUDIO/scoop-bucket && scoop install ssc-studio/lenovolegiontoolkit

Pulls the .NET runtime as a dependency.

Releases

Installer or portable ZIP

github.com/SSC-STUDIO/UniversalDeviceToolkit/releases/latest

Each release ships SHA256.txt - verify before mirroring.
