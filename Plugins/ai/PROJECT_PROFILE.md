# Project Profile

Universal Device Toolkit Plugins is the official plugin ecosystem for Universal Device Toolkit (Windows .NET / WPF). It contains SDK packages, official plugins, tests, templates, tools, and packaging assets.

## Current Engineering Priorities

- Keep plugin runtime and host contracts stable.
- Fix reliability, settings persistence, migration, and UI correctness defects.
- Preserve localization and theme-token compliance.
- Add focused regression tests for every fixed defect.
- Keep Release tests and solution build gates green.
