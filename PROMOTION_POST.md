# 🚀 Universal Device Toolkit — Now with Plugin Extensions + 2300+ Tests

**UDT** is an open-source Windows device utility (formerly Lenovo Legion Toolkit) that gives you:

## ✨ Key Features
- 🎮 **Full hardware control** for Legion/LOQ/IdeaPad Gaming (Fn+Q, RGB, fan curves, dGPU)
- 🔌 **Plugin extensions** — install CPU/GPU/network/shell tools without bloating the base app
- 🚫 **Zero telemetry, zero account, zero background service**
- 🧩 **Basic mode** for non-Lenovo PCs (plugins + system tools still work)
- 🎨 **Themes, localization, custom profiles**

## 🆕 What's New (v5.x)
- **Plugin system overhaul** — hot-reload, sandbox, dependency resolution
- **2300+ unit tests** passing (0 failures)
- **FlaUI automated UI tests** (WinRT OCR verification pipeline)
- **Global hook leak fixed** — no more system stutter after app exit
- **i18n** — 25+ languages, community-driven translations
