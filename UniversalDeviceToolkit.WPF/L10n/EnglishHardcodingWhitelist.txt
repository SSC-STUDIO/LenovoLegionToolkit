# English Hardcoding Whitelist – UniversalDeviceToolkit.WPF
#
# Source: hardcoding_audit.md in the same audit directory.
#
# This list mirrors that audit. Any literal English string that ships
# inside the WPF project and is NOT a resource key must appear here with
# one of the following tags:
#
#   [BRAND]        third-party product, library or vendor name
#   [TECH_ABBREV]  technical abbreviation / measurement unit / WPF enum
#   [URL]          full qualified URL or hyperlink target (host part)
#   [LICENSE]      license or contract identifier
#   [PLACEHOLDER]  XAML default that is overwritten by code-behind before the
#                  control becomes visible to the user
#   [GLYPH]        single Unicode glyph used as a visual mark (bullets,
#                  pipes, dashes used as separators)
#
# Anything NOT in this list, that is user-facing English, and that has
# not been moved into Resources/Resource.resx is treated as an audit
# failure by UniversalDeviceToolkit.Tests/WPF/ResourceHardcodingGuardTests.cs.
#
# Lines that begin with `#` are comments.
#
# Section format: <TAG> :: <path relative to repo root> :: <literal>
